From lib/metrics.ts:
```typescript
export interface MetricDelta {
  value: number;        // valor actual
  previous: number;
  deltaPct: number | null; // null cuando previous === 0 (entonces isNew === true)
  improved: boolean;    // dirección; YA invertida para position en Phase 3
  isNew: boolean;       // true solo cuando previous === 0
}
export interface MetricDeltas { clicks: MetricDelta; impressions: MetricDelta; ctr: MetricDelta; position: MetricDelta; }
```
Nota: `improved` ya trae la inversión de posición horneada en Phase 3 (metrics.ts línea ~99-108). El builder NO vuelve a invertir; solo mapea `improved` a color/flecha.
`ctr` es fracción 0-1 (mostrar como %). `position` es promedio (mostrar 1 decimal).
