Purpose: All branch logic (empty arg, none, multiple, already-present, success) lives here behind unit tests, so wave 3's dispatcher is pure routing.
Output: `lib/commands/add.ts` and `lib/commands/remove.ts` (+ tests). `npm test` and `npm run typecheck` pass.
