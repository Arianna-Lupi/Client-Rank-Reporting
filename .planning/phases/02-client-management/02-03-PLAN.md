## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Slack -> api/slack/command.ts | Any HTTP caller can hit the endpoint; only a valid Slack HMAC over the raw body within 5 min may proceed. |
| command field -> router | The parsed `command` selects a handler; unknown commands must be rejected, not executed. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-06 | Spoofing | api/slack/command.ts | mitigate | `verifySlackSignature` over the raw body runs once before any parse/route/backend work; failure returns 401. Preserved verbatim from Phase 1; covered by lib/slack/verify.test.ts. |
| T-02-07 | Tampering | URLSearchParams parse | mitigate | Body is parsed only AFTER the HMAC passes, so the signed bytes are exactly what is routed. |
| T-02-08 | Elevation of Privilege | router default branch | mitigate | Unknown commands return "Comando no soportado." and never reach a handler; only /list, /add, /remove are routable. |
| T-02-09 | Information Disclosure | shell catch block | mitigate | Errors return a fixed generic Spanish message; raw body, signature headers, and secrets are never logged or returned. |
</threat_model>
